# computational-rcc-automation
# Computational Automation in Reinforced Concrete Design

An interactive, open-source computational design suite built in Python for automated RCC member sizing, multi-standard code compliance, rebar constructability verification, and embodied carbon tracking.

## Key Features

* **Multi-Code Limit State Engine:** Checks Ultimate Limit State (ULS) flexure and shear across ACI 318, Eurocode 2, and IS 456.
* **Serviceability & Deflection:** Real-time span-to-depth ($L/d$) checks and doubly reinforced steel calculations ($A_{sc}$).
* **Constructability Detailing:** Dynamic verification of horizontal rebar clear spacing against maximum aggregate size ($d_{agg}$).
* **Sustainability & Life-Cycle Analysis:** Embodied carbon ($\text{kgCO}_2\text{e}$) and cost modeling responding dynamically to carbon taxation indices.
* **Generative Design Auto-Optimizer:** Deterministic grid-search module to identify the top 3 most cost-effective, code-compliant cross-sections.
